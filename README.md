# Cristiano Medeiros

Site pessoal de Cristiano Medeiros, empresário e economista, com apresentação e vitrine dos negócios Valore Condomínios, Átrio Licitações, Oxigênio Educação e Stravo IA. Escopo em [PRODUCT.md](PRODUCT.md).

## Executar

Requisitos: Node.js 22+ e pnpm 10.

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm check        # lint, tipos, regras, testes e build
```

Não há variáveis de ambiente obrigatórias nem banco de dados.
